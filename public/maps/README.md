# Подложка для карты сервера

Панель рисует карту сеткой координат, а спутниковый снимок можно добавить самому:
положите сюда квадратную картинку с именем мира и расширением `.jpg`, например

    chernarusplus.jpg
    enoch.jpg
    sakhal.jpg

Имя мира панель берёт из `hello.json` мода-моста (это часть имени миссии после
точки: `dayzOffline.chernarusplus` → `chernarusplus`).

Картинка должна быть квадратной и покрывать всю карту от угла `0 0` до
`<размер> <размер>` — тогда метки игроков совпадут с местностью. Готовых
снимков в панели нет: это чужие текстуры на гигабайты, распространять их
вместе с панелью нельзя.
