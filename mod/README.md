# @DayZPanelBridge — серверный мод-мост для DayZ Panel

Мод связывает игровой сервер с панелью: отдаёт ей состояние игроков и всё, что
они делают, и выполняет команды панели (сообщение, кик, телепорт, лечение,
выдача предметов, инвентарь).

* **Мод только серверный.** Игрокам скачивать нечего, ключи и подписи не нужны,
  никто из них о моде не узнает.
* **Никакой сети.** Обмен идёт файлами в папке профиля сервера
  (`<профиль>\panel`). Ни портов, ни интернета, ни платных подписок.
* **Ничего не ломает.** Если панель не запущена, мод просто пишет файлы; если
  папка недоступна — сообщает об этом в `script.log` и работает дальше.

Протокол обмена целиком описан в [`../docs/bridge-mod-prompt.md`](../docs/bridge-mod-prompt.md).

## Установка (2 минуты)

1. Скопируйте папку **`@DayZPanelBridge`** рядом с `DayZServer_x64.exe`
   (в корень сервера, туда же, где `serverDZ.cfg`).
2. Добавьте мод в строку запуска сервера **как серверный**:

   ```
   -serverMod=@DayZPanelBridge
   ```

   Если серверные моды уже есть — через точку с запятой:
   `-serverMod=@MyServerMod;@DayZPanelBridge`

   В панели это делается автоматически: вкладка **«Модификации»** →
   **«Добавить локальный мод»** → указать папку `@DayZPanelBridge` и тип
   «серверный». Тогда мод сам попадёт и в `.bat`, и в запуск из панели.
3. Запустите сервер.
4. Откройте в панели вкладку **«Карта»** — она должна показать игроков вместо
   инструкции.

### Как убедиться, что мост работает

После запуска сервера в папке профиля появляется:

```
<профиль>\panel\
  config.json     настройки мода
  hello.json      версия мода, мир, размер карты
  snapshot.json   состояние игроков, обновляется каждые 3 секунды
  out\            файлы событий (панель их читает и удаляет)
  in\             команды панели
```

Если `hello.json` не появился — смотрите `script.log` сервера, там будут строки
`[PanelBridge] …`.

## Настройки мода

Файл `<профиль>\panel\config.json` создаётся при первом запуске:

```json
{
  "v": 1,
  "enabled": true,
  "snapshotSeconds": 3,
  "flushSeconds": 1,
  "flushEvents": 200,
  "commandPollSeconds": 1,
  "maxEventsPerSecond": 300,
  "maxOutFiles": 2000,
  "maxInventoryDepth": 4,
  "events": {
    "connect": true, "spawn": true, "disconnect": true,
    "death": true, "kill": true, "damage": true, "shot": true,
    "chat": true, "item_take": true, "item_drop": true, "item_move": false,
    "action": true, "vehicle": true, "build": true,
    "container_open": true, "placement": true,
    "unconscious": true, "bleeding": true
  }
}
```

* `enabled: false` — полностью выключить мост, не снимая мод.
* `snapshotSeconds` — как часто обновляется состояние игроков (и метки на карте).
* `maxEventsPerSecond` — предохранитель: в замесе события идут лавиной, лишнее
  отбрасывается, а счётчик потерянного панель показывает.
* Флаги в `events` выключают отдельные типы событий — выключенный тип не пишется
  вовсе и не тратит ресурсы.

Изменения читаются при **запуске сервера**.

## Что попадает в журнал

Точные детали — вход и выход, урон с оружием, зоной и дистанцией, выстрелы,
смерти и убийства, поднятие и выброс вещей, стройка и разбор баз, чат, двигатель
транспорта, посадка и высадка, потеря сознания, кровотечение.

Отдельно стоит событие **`action`**: мод перехватывает завершение *любого*
действия игрока и пишет класс действия и объект. Так в журнал сами попадают
открытие дверей и машин, еда, питьё, перевязка, разжигание костра, взлом,
копание, ремонт — и то, что появится в новых патчах или других модах, без правки
мода.

## Пересборка мода

Мод собран заранее, и трогать сборку не нужно. Если правили исходники в
`DayZPanelBridge\` — запустите **`build-pbo.bat`**:

* если установлены **DayZ Tools**, сборка пойдёт через официальный AddonBuilder;
* если нет — панель соберёт PBO своим упаковщиком (нужен только Node.js).

Скриптовому моду бинаризация не требуется: движок читает `.c` и `config.cpp` из
PBO как есть, поэтому оба способа дают рабочий мод.

Вручную то же самое:

```bat
node ..\tools\pack-pbo.js DayZPanelBridge "@DayZPanelBridge\addons\dayzpanelbridge.pbo" DayZPanelBridge
node ..\tools\pack-pbo.js --verify "@DayZPanelBridge\addons\dayzpanelbridge.pbo"
```

## Если что-то не работает

**В `script.log` ошибка компиляции скрипта.** Значит в вашей версии игры
изменился какой-то метод движка. В логе указан файл и строка. Все команды и
хуки намеренно разложены по маленьким функциям: неисправную можно закомментировать
целиком — остальной мост продолжит работать. Сообщите строку из лога, и правка
займёт минуту.

Перед сборкой полезно прогнать проверку исходников:

```bat
node ..\tools\check-enforce.js DayZPanelBridge
```

Она ловит то, что роняет весь модуль скриптов сразу:

* экранированные кавычки в строковых литералах (`"\""`) — парсер Enforce обрывает
  на них файл;
* многострочный вызов, у которого закрывающая скобка стоит на отдельной строке, а
  последний аргумент не заканчивается запятой;
* ключевые слова (`out`, `ref`, …) как имена переменных;
* несходящиеся фигурные скобки.

Компилятором она не является: типы и имена методов проверяет только сама игра.

### История поломок (чтобы не наступить снова)

| Версия | Ошибка в `script.log` | Причина | Как правильно |
|---|---|---|---|
| 1.0.0 | `CParser: quoted string not closed` | литерал с экранированной кавычкой | кавычка, слэш и переводы строк строятся из ASCII-кодов (`int.AsciiToString()`); в исходниках нет ни одной escape-последовательности |
| 1.0.1 | `Invalid statement ')'` | вызов, разбитый на строки, где последний аргумент без запятой перед `);` | вызовы держатся в одной строке; если переносить — последний аргумент тоже с запятой, как во всех ванильных скриптах |

**`hello.json` не появляется.** Мод не загрузился: проверьте, что папка
`@DayZPanelBridge` лежит рядом с `DayZServer_x64.exe`, а в строке запуска стоит
именно `-serverMod=`, и что внутри есть `addons\dayzpanelbridge.pbo`.

**Панель пишет «мод-мост не на связи», хотя сервер работает.** Панель смотрит в
папку профиля того сервера, который выбран в панели. Проверьте, что путь к
профилю в настройках сервера совпадает с `-profiles=` в строке запуска.

**События есть, а карта пустая.** Карта рисуется по `snapshot.json`; если он
старше 20 секунд, панель считает мост оффлайном. Посмотрите, обновляется ли файл.

## Чего мод намеренно не делает

* **Не сохраняет мир по команде** — надёжного способа сделать это из скрипта нет;
  для этого есть плановый перезапуск, при котором сервер сохраняется сам.
* **Не передаёт пинг игрока** — движок не отдаёт его серверным скриптам так,
  чтобы на это можно было положиться. Пинг видно в списке игроков BattlEye.
* **Не хранит IP.** В событии подключения только короткий необратимый отпечаток:
  по нему видно «тот же адрес или другой», а сам адрес нигде не лежит.
* **Не трогает игровой процесс.** Мод только читает состояние и выполняет
  команды администратора; никаких изменений баланса, лута или правил.
