# Как настроить и запустить

Порядок именно такой: каждый шаг проверяется до перехода к следующему, иначе
потом непонятно, что именно не работает.

---

## 1. Панель (5 минут)

Нужен **Node.js 18 или новее** — <https://nodejs.org>, обычный установщик.

```bat
git clone -b claude/repo-overview-4bbd9m https://github.com/DogStay/Paneldayzserver.git
cd Paneldayzserver
install.bat
start-panel.bat
```

Если панель уже стоит — обновление:

```bat
cd Paneldayzserver
git pull
npm install
start-panel.bat
```

`npm install` теперь обязателен: появилась зависимость `mysql2`.

Окно с панелью **не закрывайте** — это и есть сервер панели. В нём же
печатаются адрес, порт, мастер-ключи и адрес мастера настройки.

## 1.1 Мастер настройки — всё в одном месте

Откройте на самой машине с панелью:

```
http://127.0.0.1:8787/setup.html
```

Одна страница, сверху вниз: панель, SteamCMD, сервер DayZ, сообщения в игру,
карта, прописка игроков, Discord (включая токен бота), аккаунты, общая база,
CFTools. Сверху — список «Готовность»: что уже работает, а что мешает и почему.
Править `config/config.json` руками больше не нужно.

Страница открывается **только с этой машины** и без входа: на ней видны и
задаются пароли и токены, поэтому снаружи она отдаёт 403 даже владельцу. Для
настройки по сети остаются обычные «Настройки» — там вход и права.

Секреты страница не показывает никогда: в поле написано «задано» или «не
задано». Пустое поле при сохранении ничего не стирает — для этого есть ссылка
«Стереть».

Дальше — обычная панель: `http://127.0.0.1:8787`.

## 2. Первый аккаунт — владелец

Мастер-ключи теперь нужны **только один раз**: чтобы владельцем стал хозяин
панели, а не случайный человек.

1. на странице входа нажмите **«Зарегистрироваться»**;
2. имя, логин, пароль (от 8 знаков);
3. в поле **«Мастер-ключ»** — любой из трёх ключей из окна панели;
4. «Стать владельцем панели».

После этого вход по ключам отключается сам, дальше — только логин и пароль.

## 3. Сервер DayZ в панели

**Мои серверы → Создать сервер**: имя, слоты, порты, пароли. Панель поставит
файлы через SteamCMD, создаст `serverDZ.cfg` и `.bat` запуска.

Если сервер уже стоит — создайте сервер и укажите **существующую папку**: панель
подхватит конфиг, моды и профиль как есть.

Проверка: на вкладке **Обзор** видно состояние, кнопка «Запустить» поднимает
сервер, в консоли панели идёт лог.

## 4. Мод-мост (карта, инвентарь, журнал действий)

Без него не работают карта, инвентарь и подробный журнал — всё остальное работает.

1. распакуйте `@DayZPanelBridge` из присланного архива рядом с
   `DayZServer_x64.exe` (или положите папку в `@ServerMods`);
2. в строке запуска добавьте `-serverMod=@DayZPanelBridge`
   (если серверных модов несколько — через точку с запятой:
   `-serverMod=@ServerMods;@DayZPanelBridge`);
3. запустите сервер.

Проверка: вкладка **Карта** перестаёт показывать «мод-мост не на связи», в папке
`<профиль>\panel` появляется `hello.json`. Мод серверный — **игрокам скачивать
нечего**, ключи не нужны.

## 5. Подложка карты

**Настройки сервера → «Подложка карты»**. Для карты любого размера, включая
150 МБ:

1. «Выберите файл» → картинка карты целиком (квадратная, без рамок);
2. **«Нарезать на тайлы»** — браузер порежет её у себя и отправит панели куски.

Ждите окончания: под кнопкой идёт счётчик тайлов. Дальше карта работает без
интернета. Небольшую картинку можно просто «Загрузить целиком».

## 6. Доступ с других компьютеров

**Настройки сервера → «Доступ снаружи» → «Проверить»**, затем «Открыть панель
наружу». Панель сама сменит адрес прослушивания и откроет порт в брандмауэре.

Заходить: `http://ваш-ip:8787`, вход — логином и паролем.

> По HTTP пароль идёт по сети открытым текстом. Если панель смотрит в интернет,
> включите TLS (`panel.tls`) или поставьте перед ней reverse-proxy с
> сертификатом — панель предупреждает об этом на странице входа.

## 7. Аккаунты и права

**Настройки сервера → «Аккаунты и права» → «Новый аккаунт»**: имя, логин,
пароль, роль.

Готовые роли: `Владелец`, `Администратор`, `Модератор` (карта, игроки, правка
инвентаря, журнал), `Наблюдатель` (только смотреть), `Только логи`.

Кнопка со **щитом** у аккаунта — точные права: галочка добавляет возможность
поверх роли, снятая — отбирает лично у этого человека. Вкладки, на которые прав
нет, у человека просто не показываются.

## 8. Вход через Discord (по желанию)

1. <https://discord.com/developers> → **New Application**;
2. **OAuth2 → Redirects** → добавьте
   `http://ваш-адрес:8787/api/auth/discord/callback` (ровно тот адрес, по
   которому заходят люди);
3. скопируйте **Client ID** и **Client Secret**;
4. в панели: **Настройки → «Аккаунты и права»**, включите вход через Discord,
   вставьте ID и Secret, тот же Redirect URI.

Новый человек, вошедший через Discord, по умолчанию **ждёт подтверждения**
владельцем — включите его в списке аккаунтов.

## 9. Общая база с сайтом и ботом (по желанию)

Нужна для объединения панели, сайта и бота. Пока выключена, панель работает на
файлах, как раньше.

1. в **XAMPP Control Panel** запустите **MySQL**;
2. в phpMyAdmin убедитесь, что база есть (у вас это `tfl_bot`);
3. в `config/config.json` включите:

```jsonc
"panel": {
  "database": {
    "enabled": true,
    "host": "127.0.0.1",
    "port": 3306,
    "user": "root",
    "password": "ваш пароль",
    "name": "tfl_bot"
  }
}
```

4. перезапустите панель и откройте `http://127.0.0.1:8787/api/db` — там видно,
   подключилась ли она и какие таблицы видит. Если в списке есть ваши
   `user_profiles` и `site_*`, панель смотрит в ту же базу, что сайт и бот;
5. `POST /api/db/init` создаст таблицы панели (`panel_identity`,
   `panel_verify_sessions`, `panel_audit`). Чужие таблицы не меняются.

Если что-то не так, `/api/db` пишет причину прямо: «MySQL не отвечает —
проверьте XAMPP», «отказал в доступе», «базы нет — создайте в phpMyAdmin».

## 10. Если что-то не работает

| Симптом | Где смотреть |
|---|---|
| панель не открывается с другого компьютера | «Доступ снаружи» → «Проверить» — покажет, на каком шаге обрыв |
| карта пустая | «Подложка карты» → «Проверить источник» либо нарежьте свою картинку |
| «мод-мост не на связи» | вкладка «Карта» пишет причину; проверьте `-serverMod=` и путь к профилю |
| инвентарь не открывается | нужен мод 1.0.6 или новее |
| действий админов из VPP нет в журнале | «Логи» → строка про VPPAdminTools и кнопка «Перечитать» |
| забыт пароль владельца | остановите панель, удалите `data\users.json`, запустите — панель снова попросит создать владельца по мастер-ключу |

Логи панели — в папке `logs`, там же журнал событий по дням.
