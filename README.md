# DayZ Panel — веб-панель управления серверами DayZ Standalone (Windows)

Локальная панель на Node.js + Express. Создаёт серверы DayZ «с нуля» через мастер,
подписывается на модификации прямо из Steam Workshop, собирает `.bat` запуска,
открывает порты в брандмауэре Windows, следит за обновлениями модов и пишет
подробные отчёты, когда что-то ломается.

Интерфейс — тёмный, анимированный, на русском языке, без единого внешнего ресурса:
шрифты системные, иконки нарисованы прямо в коде. Интернет нужен только в трёх
случаях: разовый `npm install`, работа SteamCMD и поиск модов в Workshop.

---

## Что умеет

| Возможность | Где живёт |
|---|---|
| **Мастер создания сервера** — 4 шага (название, слоты, пароли → карта, порты, время → папка и SteamCMD → проверка), затем автоматическая установка файлов DayZ Server | `src/services/instances.js` |
| **Несколько серверов** в одной панели: свои папки, порты, моды и настройки у каждого | `src/config.js` |
| **Подписка на модификации** — поиск по названию или Workshop ID/ссылке, добавление в список, кнопка «Загрузить» с живым прогрессом | `src/services/workshop.js`, `src/services/mods.js` |
| **Автообновление модов** перед стартом: версия сверяется по `appworkshop_221100.acf`, изменившееся перекладывается в папку сервера | `src/services/mods.js` |
| **Автогенерация `.bat`**: `-mod=`, `-serverMod=`, порты, конфиг, профили — всё из настроек панели | `src/services/batgen.js` |
| **Автооткрытие портов** через `netsh advfirewall`, порты берутся из конфига | `src/services/firewall.js` |
| **Старт / стоп / перезапуск**, статус, аптайм, живой лог сервера из `*.RPT`, `*.ADM`, `script.log` | `src/services/serverProcess.js`, `logTail.js` |
| **Правка `serverDZ.cfg`** прямо в браузере + синхронизация имени, паролей, слотов, карты и query-порта | `src/services/serverCfg.js` |
| **Диагностика**: отчёт одной кнопкой + автоматический отчёт при падении сервера | `src/services/diagnostics.js` |

## Требования

* Windows 10/11 или Windows Server 2016+
* [Node.js LTS](https://nodejs.org) (18 или новее), при установке отметьте «Add to PATH»
* [SteamCMD](https://developer.valvesoftware.com/wiki/SteamCMD) — например в `C:\SteamCMD`
* Аккаунт Steam, **на котором куплен DayZ** (анонимно Steam не отдаёт ни файлы сервера, ни моды)
* 15+ ГБ свободного места под каждый сервер

## Установка и первый запуск

### 1. Скачать панель

```bat
git clone https://github.com/DogStay/Paneldayzserver.git C:\DayZPanel
cd C:\DayZPanel
```

### 2. Установить зависимости

Двойной клик по **`install.bat`** (или `npm install --omit=dev`).
Это единственный шаг, требующий интернета помимо самого Steam.

### 3. Разовый вход в Steam (если включён Steam Guard)

```bat
C:\SteamCMD\steamcmd.exe +login ВАШ_ЛОГИН +quit
```

Введите пароль и код Steam Guard. Дальше SteamCMD использует сохранённую сессию,
и пароль в панели можно не указывать вообще.

### 4. Запустить панель

Двойной клик по **`start-panel.bat`** → откроется <http://localhost:8787>.

> **Запускайте от имени администратора** (ПКМ → «Запуск от имени администратора»),
> иначе `netsh` не сможет создавать правила брандмауэра. Панель предупредит об этом
> и всё равно запустится: правила можно применить позже через
> «Порты» → «.bat для админа».

### 5. Создать сервер

При первом запуске панель сама предложит мастер. Дальше:

1. **Основное** — название, слоты, пароль входа, пароль администратора.
2. **Мир и сеть** — карта (Chernarus+ / Livonia / Sakhal), ускорение времени,
   игровой порт и Steam query порт, режим от первого лица.
3. **Установка** — папка сервера, путь к `steamcmd.exe`, логин Steam.
4. **Проверка** — сводка и кнопка «Создать и установить».

SteamCMD скачает файлы сервера (3–5 ГБ), панель создаст `serverDZ.cfg` и `.bat`.
Прогресс виден прямо в мастере, в плашке справа внизу и в консоли логов.

### 6. Подписаться на модификации

Вкладка **«Модификации»** → **«Подписаться на модификации»**:

* введите название мода (например `Trader`) **или** его Workshop ID / ссылку;
* нажмите «Найти», добавьте нужные моды в список кнопкой «Добавить»;
* нажмите **«Загрузить»** — SteamCMD скачает моды, панель разложит их в папку
  сервера и скопирует ключи `.bikey` в `keys`.

Порядок модов в списке = порядок в `-mod=`. Зависимости (`@CF`, `@Dabs Framework`)
перетащите наверх мышью.

### 7. Запустить

Кнопка **«Запустить»** в шапке сервера.

## Что происходит при нажатии «Запустить»

1. **Проверка** путей и портов — при проблеме запуск не начнётся, а панель скажет, чего не хватает.
2. **Брандмауэр** — `netsh advfirewall firewall add rule` для игрового порта, query-порта
   и всех дополнительных диапазонов (in + out, имена вида `DayZ Panel - UDP 2302`).
   Существующие правила не дублируются.
3. **`serverDZ.cfg`** — подставляются `hostname`, `password`, `passwordAdmin`, `maxPlayers`,
   `steamQueryPort`, ускорение времени, карта. Остальное содержимое файла не трогается.
4. **Моды** — SteamCMD проверяет включённые моды; изменившиеся копируются
   (или симлинкаются) в папку сервера, ключи раскладываются в `keys`.
   В лог попадает строка вида `↑ Trader (1590841260): ОБНОВЛЁН`.
5. **`.bat`** — генерируется файл запуска со всеми актуальными параметрами.
6. **Запуск** — `DayZServer_x64.exe` стартует с теми же аргументами, что в `.bat`;
   панель запоминает PID и начинает читать логи профиля.

Любой шаг отключается на вкладке «Настройки сервера» → «Что делать при запуске».

## Если сервер не запускается — диагностика

Панель специально сделана так, чтобы проблему можно было переслать одним файлом.

**Вручную:** вкладка **«Диагностика»** → **«Собрать отчёт»**.
Файл `diagnostic-report-ГГГГ-ММ-ДД_ЧЧ-ММ-СС.txt` появляется **в корне папки панели**
(там же, где `start-panel.bat`). Его можно посмотреть прямо в браузере, скачать
кнопкой или скопировать в буфер.

**Автоматически:** если сервер завершился сам или запуск сорвался, панель сохраняет
`logs\crash-<имя сервера>-<дата>.txt` — без всяких кнопок. На вкладке «Обзор»
появится красная плашка со ссылкой на отчёт.

Что внутри отчёта:

* версия панели, ОС, Node.js, свободная память и место на диске;
* состояние SteamCMD: путь, наличие файлов, логин, есть ли `.acf`;
* по каждому серверу — все пути с пометкой «ЕСТЬ / НЕ НАЙДЕН», настройки, порты;
* список модов: скачан / разложен / включён / версия;
* точная командная строка запуска;
* содержимое папки сервера, `serverDZ.cfg` и сгенерированного `.bat`;
* последние строки лога панели и логов сервера (`*.RPT`, `*.ADM`, `script.log`).

**Пароли (Steam, вход на сервер, админский, RCON) в отчёт не попадают** — они
затираются даже в дампе `serverDZ.cfg`. Файл можно пересылать как есть.

Кроме отчётов панель постоянно пишет `logs\panel-ГГГГ-ММ-ДД.log` (хранятся 14 дней).

## Поиск модов: как это работает

1. **По Workshop ID или ссылке** — запрос `ISteamRemoteStorage/GetPublishedFileDetails`.
   Ключ Web API не нужен, работает всегда. Это самый надёжный путь.
2. **По названию с ключом Web API** — `IPublishedFileService/QueryFiles`.
   Ключ бесплатно берётся на <https://steamcommunity.com/dev/apikey> и вводится
   в «Настройки сервера» → «SteamCMD и аккаунт Steam».
3. **По названию без ключа** — разбор страницы поиска Workshop. Работает «как есть»:
   если Valve поменяет вёрстку, поиск по названию может перестать находить —
   поиск по ID продолжит работать всегда.

---

## Режимы раскладки модов

* **copy** (по умолчанию) — мод физически копируется из
  `steamapps\workshop\content\221100\<id>` в `<сервер>\@Имя`. Надёжно, занимает место дважды.
* **symlink** — junction на папку workshop: экономит диск, обновление применяется
  мгновенно. Требует, чтобы оба пути были на одном томе NTFS, и обычно прав администратора.

В обоих режимах `.bikey` копируются в `<сервер>\keys` физически — иначе сервер их не подхватит.

---

## Как определяется, что мод обновился

DayZ Workshop не даёт версию без обращения в Steam, поэтому панель делает так:

1. Читает `steamapps\workshop\appworkshop_221100.acf` и запоминает `manifest` +
   `timeupdated` каждого мода.
2. Запускает `steamcmd +workshop_download_item 221100 <id>` для всех включённых
   модов одним вызовом — SteamCMD сам скачает только изменившееся.
3. Перечитывает `.acf`. Изменился `manifest`/`timeupdated` — мод считается обновлённым:
   он заново раскладывается в папку сервера, а в лог попадает строка `↑ <Имя>: ОБНОВЛЁН`.

Дополнительно панель показывает бейдж «есть обновление», если в секции
`WorkshopItemDetails` время публикации новее установленного.

## API

Всё под `/api`, ответы — JSON. Длительные операции возвращают `job.id`,
а прогресс приходит через SSE-поток `/api/stream`.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/status` | статус панели, серверов, SteamCMD, активные задачи |
| `GET` `PUT` | `/config` | общие настройки (панель, SteamCMD, аккаунт Steam) |
| `GET` | `/servers`, `/servers/suggest` | список серверов, подсказки для мастера |
| `POST` | `/servers` | создать сервер и запустить установку файлов |
| `POST` | `/servers/:id/install` `/activate` | переустановка, выбор активного |
| `PATCH` `DELETE` | `/servers/:id` | настройки и удаление сервера |
| `GET` | `/workshop/search?q=` | поиск модов по названию или ID |
| `GET` | `/mods` | список модов активного сервера |
| `POST` | `/mods/download` | скачать выбранные моды (задача с прогрессом) |
| `POST` | `/mods/update` `/deploy` `/adopt` `/reorder` | обновление, раскладка, подключение, порядок |
| `PATCH` `DELETE` | `/mods/:id` | включение/тип/удаление мода |
| `GET` `POST` | `/bat` | предпросмотр и запись `.bat` |
| `GET` `POST` `DELETE` | `/firewall`, `/firewall/apply`, `/firewall/bat` | правила брандмауэра |
| `GET` `PUT` `POST` | `/servercfg`, `/servercfg/sync` | работа с `serverDZ.cfg` |
| `POST` | `/server/start` `/stop` `/restart` | управление сервером |
| `GET` `POST` `DELETE` | `/diagnostics`, `/diagnostics/:name` | отчёты диагностики |
| `GET` `POST` | `/jobs`, `/jobs/:id/cancel` | длительные операции |
| `GET` | `/logs`, `/stream` | лог и живой поток событий |

## Безопасность

Панель **не имеет авторизации** и по умолчанию слушает только `127.0.0.1` —
доступна лишь с самой машины сервера. Если поменять `panel.host` на `0.0.0.0`,
она станет видна в локальной сети; в интернет её выставлять нельзя (используйте
VPN или reverse-proxy с паролем).

Пароль Steam, если указан, хранится в `config/config.json` в открытом виде и
никогда не отдаётся обратно в браузер и не попадает в отчёты. Надёжнее выполнить
`steamcmd +login ЛОГИН +quit` один раз вручную и оставить поле пустым.

## Решение проблем

**«Порт 8787 занят»** — измените `panel.port` в `config/config.json`.

**Правила брандмауэра не создаются** — панель запущена без прав администратора.
Перезапустите `start-panel.bat` от имени администратора либо нажмите
«Порты» → «.bat для админа» и выполните `generated\open-firewall.bat` с правами администратора.

**SteamCMD: `Login Failure` / `Rate Limit Exceeded`** — выполните вход вручную
(`steamcmd +login ЛОГИН +quit`), подтвердите Steam Guard и повторите.

**SteamCMD: `No subscription`** — аккаунт не владеет DayZ.

**Поиск по названию ничего не находит** — вставьте Workshop ID или ссылку на мод,
либо укажите ключ Steam Web API в настройках.

**Сервер стартует и сразу падает** — откройте автоматический отчёт из папки `logs`.
Чаще всего это `verifySignatures = 2` без нужных `.bikey` в `<сервер>\keys` или
мод-зависимость, стоящий в `-mod=` ниже зависящего от него (поднимите `@CF` вверх).

**Лог сервера пуст** — сервер запущен без `-dologs -adminlog -netlog` либо указана
не та папка профиля. Проверьте «Настройки сервера» → «Пути сервера».

**Мод не появился в игре** — убедитесь, что у него бейдж «готов», он включён
чекбоксом и попал в предпросмотр на вкладке «Файл запуска».

## Разработка

```bash
npm install
npm start           # http://localhost:8787
npm run check       # быстрая проверка синтаксиса
```

Единственная внешняя зависимость — Express. Фронтенд собирать не нужно.

Панель запускается и на Linux/macOS (удобно для доработки интерфейса): `netsh` и
запуск `DayZServer_x64.exe` там не работают, о чём панель честно предупреждает,
остальные функции доступны.

Для отладки поиска модов без интернета можно подменить адреса Steam:

```bash
DAYZPANEL_STEAM_API=http://127.0.0.1:9999 \
DAYZPANEL_STEAM_COMMUNITY=http://127.0.0.1:9999 npm start
```
