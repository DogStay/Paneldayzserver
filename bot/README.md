# Discord-бот панели

Верификация игроков и автоматическая прописка на сервер. Бот **ничего не хранит
и ничего не решает сам** — вся истина в панели, поэтому расходиться нечему.

## Как это работает

1. Игрок пишет `/verify` — бот отвечает **только ему** одноразовой ссылкой.
   Ссылка личная: кто её открыл, тот и привяжет свой Steam к этому Discord.
2. Игрок входит через **Steam** на странице панели. Пароль он вводит на сайте
   Steam; ни бот, ни панель его не видят. Владение аккаунтом подтверждает сам
   Steam (OpenID), поэтому подделать steamId64 нельзя.
3. Панель пишет связку и **ставит прописку в очередь на диске**. Дальше она
   допишет игрока в файлы сервера сама: с повторами, без дублей, даже если файл
   занят сервером или панель перезапустили. Именно поэтому «человек пришёл, а
   его не прописало» больше не случается — прописка не зависит от бота.
4. Бот выдаёт роль и ставит ник из Steam. Если бот в этот момент лежал, он
   догонит пропущенных при старте (`/api/verify/pending`, раз в 30 с).

## Настройка

Токен бота и ID (сервер Discord, роль «проверен», канал журнала) задаются **в
панели**, в мастере настройки: на машине с панелью откройте
`http://127.0.0.1:8787/setup.html` → раздел «Discord».

Боту локально нужны только две строки. Скопируйте `.env.example` в `.env`:

```
PANEL_URL=http://127.0.0.1:8787
PANEL_TOKEN=dzp_…
```

`PANEL_TOKEN` — API-токен **с правами admin**: панель → Настройки → «Аккаунты и
права» → API-токены.

## Запуск

Windows — `start-bot.bat` в корне репозитория. Вручную:

```bash
pip install -r requirements.txt
python bot.py
```

Панель должна быть запущена: настройки бот берёт у неё.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/verify` | все | выдаёт личную ссылку на подтверждение Steam |
| `/status [участник]` | все | подтверждён ли Steam и прописан ли игрок в каждом файле |
| `/whitelist участник steam_id` | админы | связать и прописать вручную |

## Права бота в Discord

- включите **Server Members Intent** в настройках приложения (Bot → Privileged
  Gateway Intents) — без него нельзя выдать роль по id;
- роль бота должна быть **выше** выдаваемой роли, иначе Discord ответит
  «нет прав». Бот пишет об этом прямо.

## Если что-то не так

Бот печатает причину словами, а не трейсбек:

| Сообщение | Что делать |
|---|---|
| `панель недоступна по адресу …` | запустите панель, проверьте `PANEL_URL` |
| `Нужен API-токен с правами admin` | токен `read` не годится: в ответе настоящий токен бота |
| `В панели не задан токен бота` | мастер настройки → Discord → «Токен бота» |
| `Discord не принял токен бота` | Bot → Reset Token, вставьте новый в мастер настройки |
| `нет прав выдать роль` | поднимите роль бота выше выдаваемой |
